留刻1.5.1 — Android 动态照片 ↔ Apple Live Photo

系统要求
macOS 12 Monterey 或更新系统。GitHub 发布的通用版同时支持 Intel 与 Apple Silicon。
使用应用无需 Python、Swift、Xcode、FFmpeg 或其他额外环境。

开始
先把 DMG 中的 留刻拖入 Applications，然后从「应用程序」打开。
1. 点击「添加照片」选择文件、文件夹或系统图库，再选择转换方向。
2. 在保存位置菜单选择交付目标，在「导出设置」中选择格式；输出文件夹必须在原片目录之外。
3. 点击开始，在队列与报告中查看进度、已有结果和错误；需要时停止。
4. 手动导入 Apple「照片」时，同时选择同名 JPEG/HEIC 与 MOV。
5. 独立辅助轨 MOV 是普通视频，不与 Live Photo 配对一起导入。

预览与工作台
单一工作台提供常驻分类与计数，默认显示可转换；设置从「导出设置」打开。
添加后，来源按钮显示当前来源并保留继续添加能力；保存位置按钮显示当前目标并可修改。
照片工具栏的更多菜单可清空当前列表，原片与已生成的结果不会删除。
可切换缩略图与列表；范围筛选只改变显示，开始转换仍处理全部来源。
点击「预览」展开窗格后，照片下方的标记表示封面位置，鼠标悬浮时间条可预览对应视频帧，移开恢复照片。
无法定位封面或读取视频时明确提示，不推测封面位置。

高清候选封面
预览窗格的「封面」菜单或照片右键菜单可选择辅助轨高清候选，动态仍使用主运动轨。
「Live Photo ＋ 高清封面」支持每张都导出为实况照片，或仅主照片实况、其余静态。
辅助候选会解码为 JPEG，不沿用原始封面的 HDR 增益图；原片保持只读。

图库与共享
图库默认读取未修改原片，可以明确选择完整编辑版；不同版本资源不混配。
iCloud 下载和运行期间监测需要明确启用；应用退出后停止监测。
安卓转苹果可导入新 Live Photo 并关联目标相册。
苹果转安卓可导出到文件夹、调用系统共享，或两者同时交付。
系统共享菜单里的服务取决于本机安装与扩展，不保证特定应用可用。
最近结果可重试交付、查看文件或清理应用任务缓存。
缓存清理不删除用户输出文件夹中的文件或图库资产。

图像和时间
已有 Ultra HDR 原样保留。仅对能可靠解释的旧 Apple/ISO 增益数据尝试转换。
SDR 不生成 HDR；未知私有 HDR 会保留数据或明确报错，不捏造增益图。
HEIC 支持已验证的结构；未知项目、复杂位置或加密结构可被拒绝。
音视频不重新编码，源封面通过实际视频样本时间映射，输出执行数据与 PTS 核对。
不能解释的时间轴、缺失配对和越界封面会报告错误。
源文件保持只读，已有结果可跳过、停止或在新结果完整校验后原子替换。
可关闭 JSON 清单与报告导出，内部仍完成校验；历史报告不会自动删除。

隐私
照片样片、转换结果、构建缓存和本地验证报告不随源码或应用分发。
报告可包含本机路径、日期、EXIF 和哈希，不应作为公开文档上传。
图库读取和写入只在用户选择对应功能时申请权限。

首次打开
应用使用本地 ad-hoc 签名，没有 Developer ID 签名和 Apple 公证。
若被 macOS 阻止，可在访达按住 Control 点按应用后选“打开”，或在系统隐私与安全性设置中允许。
正式应用与诊断构建分开；诊断截图使用虚构数据。

兼容边界
当前运行验证基于 Intel/macOS 12，ARM 与 iOS 真机尚待验证。
系统图库、iCloud、第三方共享及各品牌手机相册的最终动态/HDR 效果需要真实环境验收。
本工具不承诺所有厂商私有格式、固件或编辑后图片均可转换。
