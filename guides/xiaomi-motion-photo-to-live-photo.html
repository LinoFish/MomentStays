小米动态照片怎么转成 iPhone 实况照片？

可以在 Mac 上用 MomentStays 试一试：它能转换 Google 兼容格式的动态照片。小米文件的具体封装公开资料说法不一，若你的文件没被识别，欢迎提交样例反馈。反方向（iPhone 实况照片 → 小米动态照片）已支持。

为什么小米动态照片在 iPhone 上不动

小米相机里的「动态照片」同样是把一段短视频嵌在 JPG 里。iPhone 只认「图片 + MOV」配对的实况照片，因此直接传过去只显示静态图。小米官方开发者文档也说明，各厂商动态照片规范不统一。

操作步骤

  1. 把原文件传到 Mac用 USB 数据线 + OpenMTP（Google 的 Android File Transfer 已停止提供），或同一 Wi-Fi 下用 LocalSend。从手机 DCIM/Camera 复制原图。
  2. 打开 MomentStays首次启动若被拦截：系统设置 → 隐私与安全性 → 仍要打开。
  3. 添加文件并转换可添加单个文件、整个文件夹，或直接读取「照片」图库，支持批量。
  4. 导入「照片」结果可直接导入「照片」App 的相簿，也可另存为 JPEG/HEIC + MOV 配对文件。
  5. 同步到 iPhoneMac 与 iPhone 都开启 iCloud 照片，实况照片会自动出现在 iPhone 上，长按即可播放。
别用微信、QQ 等聊天软件或社交 App 传：三星、华为官方都说明，经第三方 App 分享后动态照片会变成静态图。云盘/网页上传也可能只剩照片，请以原文件为准。

小米支持情况

  • 小米 → iPhone：未对小米机型逐一验证。若文件属于 Google 兼容格式即可转换；不能识别时请附样例反馈，我们会据此适配。
  • iPhone → 小米：已支持，可把实况照片转成小米相册可识别的动态照片 JPEG。

常见问题

我的小米动态照片能保证转换成功吗？

不能保证。MomentStays 支持 Google 兼容格式；小米不同机型/系统版本的封装可能不同。欢迎试用，失败请在 GitHub 反馈。

能把 iPhone 实况照片发给用小米的朋友吗？

可以。用 MomentStays 转成小米格式的动态照片 JPEG，再用 LocalSend 或数据线等不压缩的方式发给对方。

转换会重新压缩视频吗？

不会。视频和音频只做封装转换（remux）并逐样本校验，不重新编码。
