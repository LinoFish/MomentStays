四样都留住

该留的，一个不少

封面

还是你选的那一帧

  • 按原时间戳对齐到对应的那一帧
  • 时间信息缺失会直接提示，不拿中间帧凑数
  • 想更清晰？部分照片可改选高清候选帧，动态不变
音视频

不重新编码

  • 原始音视频数据直接重新封装
  • 输出前逐个样本校验
  • 注：苹果 HEIC 转安卓 JPEG 时，静态图需重新编码：格式不同，且安卓对 HEIC 支持有限
连拍

还是一组

  • 识别连拍组，保留原序号
  • 代表照片由你来选
  • 缺帧不补；不想成组，也能拆成单张导出
  • 注：实验性支持 Google、三星及已知华为/荣耀格式的 JPEG 连拍，仅安卓 → 苹果；较新的华为/荣耀格式可能无法识别
HDR

能留的都留，留不了就说明

  • Ultra HDR 增益图连同参数保留
  • 不支持的 HDR 会标出，不假装转好
  • 私有 HDR 转换默认关闭，可在导出设置中开启
  • 注：苹果增益图转成安卓格式时，可能无法完全无损
  • 注：高清候选帧不含 HDR 增益图

常见问题

直接拷到 iPhone 不行吗？

不行，格式不同：动态照片拷过去只是一张静态图，连拍会散成一堆单张

会掉画质吗？

视频和音频不会，只重新封装并校验。安卓转 iPhone，照片原样保留；若改选高清候选封面，该帧会解码为 JPEG，不带原封面的 HDR；iPhone 的 HEIC 转安卓 JPEG，静态图必须重新编码（安卓对 HEIC 支持有限），HDR 增益图也可能无法完全无损

照片会上传吗？

不会，全程在你的 Mac 本地完成

能转回安卓吗？

可以，选择「Apple → Android」和对方手机品牌即可

安卓连拍转到 iPhone 还是一组吗？

实验性支持。Google、三星及已知华为/荣耀格式的 JPEG 连拍会写入苹果连拍标记，导入「照片」后回查是否成组；代表照片由你选择。较新的华为/荣耀格式可能无法识别，小米、OPPO、vivo 的连拍暂不支持

收费吗？

免费开源（GPL-3.0），觉得好用，欢迎在 GitHub 赞助
