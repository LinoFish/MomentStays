# 中英文命名与下次发布计划

状态：仅规划；在下次 Release 的编译输入冻结、构建之前实施。当前已发布版本不改，本次不修改代码、版本号、安装包、README 或网站，不运行构建、测试或发布。

## 名称与语言回退

- 英文名沿用 **MomentStays**，中文名仍为 **留刻**；默认使用英文名。
- 中文语言环境显示「留刻」；英语、其他不支持语言及语言解析失败时回退为 MomentStays。中文匹配范围应显式覆盖中文语言偏好，不能因只提供 `zh-Hans` 而遗漏其他中文环境；语言判定与系统本地化显示保持一致。
- 本要求取代 1.5.0「各语言统一显示留刻」的命名决策，仅从下次 Release 生效。

## 下次发布的修改范围

1. **应用默认值与本地化**：在 [Info.plist](../../packaging/Info.plist) 中将 `CFBundleName`、`CFBundleDisplayName` 默认值设为 MomentStays，保留英文开发语言与明确的英文回退。打包 `zh-Hans` 的 `InfoPlist.strings`，将这两个名称本地化为「留刻」；同时明确其他中文语言偏好的资源匹配策略，并在构建前检查。英文资源如覆盖名称，须与默认值一致。
2. **界面显示**：检查 App 菜单及关于、隐藏、退出等含名称项目，关于面板、主窗口及其他含产品名的窗口标题，统一按上述语言规则取名；避免硬编码「留刻」覆盖英文回退。
3. **Finder 与分发文件**：建议物理 App 包统一为 `MomentStays.app`，DMG/ZIP 及卷名等采用英文分发名，并随确定版本命名。通过中文本地化使系统支持的显示位置呈现「留刻」。物理文件名、安装包文件名与系统本地化显示是不同层次；同一安装包内的物理文件名不会随系统语言自动改名。Finder 的本地化显示须在实际安装路径检查，不能仅凭配置宣称已生效；无需为中文复制第二套 App。
4. **保持升级身份**：保留 bundle id `app.motionlive.converter`、可执行文件技术标识 `MomentStays`，以及现有偏好设置、任务记录、缓存和升级数据路径；不因显示名或 App 包名改变而迁移、重置数据。检查旧中文包名安装后的升级替换行为，避免留下两份应用；必要的替换说明随下次发布准备。
5. **语言对应的对外名称**：英文 README/网站使用 MomentStays，中文版本使用「留刻」，必要时标注另一语言名。保留既有仓库 URL `https://github.com/LinoFish/MomentStays`。仅在下次发布准备时按需同步名称、下载名及安装路径示例，本次不改对外内容。

## 执行顺序与验收

1. 下次发布先确定版本，沿用用户既有版本确定要求；本规划不预定或递增版本号。
2. **在编译输入冻结和构建之前**完成上述名称、资源打包与语言回退修改，并检查菜单/关于/窗口的取名路径及打包名称。不得先构建产物、再补改名称。
3. 沿用 Universal 同产物一次构建、测试、发布要求：名称检查通过后冻结输入，生成同一份 Universal 产物，以该产物完成验证和发布；若名称检查失败需修改输入，则重新冻结并重建，不能发布旧产物或在构建后补改包内容。
4. 随下次发布安排针对性验收：英语显示 MomentStays；简体中文及其他中文语言偏好显示「留刻」；不支持语言回退 MomentStays。分别检查菜单、关于、窗口和 Finder 安装后显示，并核对物理 App/分发文件名保持既定英文名称、升级识别和原有数据仍可用。区分 App 语言偏好与 Finder 系统语言的影响，避免将两者不同语言设置误判为失败。

本次仅保存规划，不执行上述检查或发布操作，也不修改安卓互转实现及其既有规划。Release 描述继续遵循根目录 [AGENTS.md](../../AGENTS.md)，仅简述用户可感知的 App 变化。
