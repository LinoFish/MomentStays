# 中英文命名与下次发布计划

状态：macOS 本次已实施，已通过 macOS 专项及正式产物验证，随 1.7.0 发布；iOS 仍待独立迁移。已发布旧版本不改。

## 名称与语言回退

- 默认产品名及英文名为 **MomentStays**；**留刻**仅为暂定中文翻译，中文译名尚未定稿。以下中文显示规则均以该暂定译名为候选，不改变默认英文名。
- 用户已有域名：`momentstays.linofish.com`；目标应用标识确定为 `com.linofish.momentstays`，详见[产品命名与应用标识规范](../design/产品命名与应用标识规范.md)。本次落地 macOS，iOS 保留原成套配置。
- 中文语言环境显示「留刻」；英语、其他不支持语言及语言解析失败时回退为 MomentStays。中文匹配范围应显式覆盖中文语言偏好，不能因只提供 `zh-Hans` 而遗漏其他中文环境；语言判定与系统本地化显示保持一致。
- 本要求取代 1.5.0「各语言统一显示留刻」的命名决策，从本次新 Release 生效。

## 本次 macOS 实施状态

- 本次发布版本采用 1.7.0 / build 71：旧华为人工主轨选帧、跨标签多选与应用标识迁移属于新增能力，按 minor 递增；发布前按根 AGENTS 再核对最新远端 tag/Release，版本不作为未来任务固定值。已发布1.6.1不改写。
- 默认 plist 名称 MomentStays；中文资源覆盖 zh-Hans、zh-Hant 和 zh，App 菜单、关于及窗口通过统一语言规则取名，其余语言回退英文名。物理包 MomentStays.app，不复制第二套中文 App。
- macOS bundle id 已实施为 com.linofish.momentstays。首次启动仅补拷旧偏好域中缺少的键并记录迁移，旧域保留；任务与缓存继续使用 Motion-Live 原路径。无 App Group 配置。新身份可能重新询问 Photos 权限；不访问真实 Photos 库进行自动迁移。
- 分发文件采用 MomentStays-<版本>-universal.dmg/.zip，卷名 MomentStays <版本>。旧留刻.app需要先退出；安装包不删除旧版，用户核对新版本原有结果可用后自行移除旧版。见[升级说明](../../apple/macos/packaging/UPGRADING.txt)。
- 英文 README 使用 MomentStays，中文保留留刻并说明默认名称，构建、分发和 UI 测试中的当前产物路径同步英文包名。

## 验证与后续平台边界

名称、身份与版本在最终 Universal 编译前冻结，使用同一正式 App 完成 Intel 启动、必要生产转换和 DMG/ZIP 一致性验证。模型测试验证中英文/其他语言取名，以及旧偏好缺键复制、不覆盖、可追踪与幂等语义；最终产物配置及实际启动结果记录在本地发布交接，不上传私有媒体/报告。

Finder 的显示名受系统语言和安装路径影响；App语言与Finder语言应分开判断，不仅凭 plist 声称各安装环境已验证。Photos导入与ARM真机仍须明确区分构建支持和实际验收。

iOS 工程及分享扩展仍保留原成套标识、App Group 与容器路径；迁移须统一注册、签名及真机验收，本次不扩大为 iOS 发布。具体配置关系见[应用标识规范](../design/产品命名与应用标识规范.md)。Release 正文继续遵循根目录 [AGENTS.md](../../AGENTS.md)，仅写本次用户可感知变化。
