# Mobile validation status

- Flutter iOS device archive built successfully; the IPA requires signing and compatible provisioning for the app and share extension.
- Flutter analysis passed and nine UI/service tests passed. Five iOS tests passed on the latest native integration snapshot.
- An earlier simulator build launched on iPhone and iPhone Duo. Photo and file pickers opened, and a scan completed; an ordinary PNG was rejected as an unsupported input.
- Genuine user-provided samples have not been converted or tested end to end. No conclusion is claimed about pairing, cover time, audio, video, HDR, vendor compatibility, or real-device operation.
- Direct sharing of paired Live Photos is disabled; saving a paired result to Photos is implemented but not verified with real converted samples.
- Android implementation and the later iOS-native visual redesign are not complete.
- User photographs and metadata are not included in this repository.
