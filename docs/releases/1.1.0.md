# MomentStays 1.1.0

- 原生 SwiftUI 三栏工作台，支持缩略图/列表切换、队列范围筛选与常驻交付设置。
- 照片下方显示封面时间标记；鼠标悬浮时间条可查看实际视频帧，移开后恢复静态照片。
- 顶栏和预览占位统一使用官方深浅色 Logo；界面随系统外观和强调色切换。
- 延续主线的格式限制：苹果转安卓的 HEIC 输出仅支持三星，Google/小米使用 JPEG。

最低系统要求 macOS 12。通用安装包包含 Intel 与 Apple Silicon 构建；实际运行验证基于 Intel/macOS 12，Apple Silicon 真机仍需验证。应用使用 ad-hoc 签名，未进行 Apple 公证。

验证：43 项构造媒体预览检查、3 项原生悬浮交互、15 项原生窗口布局、32 项转换引擎回归。安装包提供 DMG、ZIP 与 SHA-256 校验和。

在同步最新 main 后，另通过 70 项工作区状态、取消及双向转换集成检查。新增/修改文本已审计，未新增个人路径、媒体样片或凭证；安装包与截图保留在忽略目录。

交付验收：通用版 DMG 已通过只读挂载与映像校验；DMG 和 ZIP 内的应用均为 1.1.0（build 19），包含 x86_64、arm64，代码签名、二进制一致性及 SHA-256 校验均通过。
