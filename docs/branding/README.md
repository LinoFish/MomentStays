# 留刻（MomentStays）视觉标识

核心语句：**The moment stays. / 留住原来的瞬间。**

项目原创图标与页首素材与源码采用相同的 [GPL-3.0-only](../../LICENSE) 协议，版权署名为 Lino。

图标沿用实况照片的三层环形语言：琥珀色圆心是被留住的瞬间，白色/墨色内环是完整的静态原件，点状外环代表动态画面；外环最后四分之一化作一道渐隐弧线，表示画面正在流动。符号不依赖具体厂商标志，适用于项目头像和 macOS 应用图标。

图标提供浅色与深色两套，随系统外观切换。

| 颜色 | 浅色模式 | 深色模式 | 用途 |
| --- | --- | --- | --- |
| 背景（上→下渐变） | `#FFFFFF` → `#ECEEF1` | `#2A3442` → `#141A22` | 图标底板 |
| 线条 | `#1F2933` | `#F2F4F5` | 内环、外环圆点与运动弧线 |
| 琥珀 | `#F0A43C` | `#F4B860` | 被留住的关键帧 |

- [项目图标](icon.svg)：1024×1024 SVG，通过 `prefers-color-scheme` 自动适配深浅色。
- [浅色图标](icon-light.svg) 与 [深色图标](icon-dark.svg)：单独的 1024×1024 SVG。
- [README 页首](github-header.svg)：1280×420，包含项目名称和四项核心价值。
- 原生应用图标由 `packaging/Icon.swift` 使用同一几何与色值绘制（`make-icon <iconset> light|dark`）；构建脚本生成 `AppIcon.icns` 与 `AppIconDark.icns`。`gui/AppIconAppearance.swift` 在运行时按系统外观切换 Dock 图标；Finder 中显示浅色版。

图形全部由代码绘制，不使用用户照片、样片截图、EXIF、时间戳或固定内容指纹。SVG 源文件可直接随仓库发布，不需要为个人媒体的忽略规则添加例外。

## App 强调色

App 控件采用与品牌琥珀相近的系统原生橙色（macOS `NSColor.systemOrange`，SwiftUI `.orange`），随系统深浅色与对比度设置适配。图标仍保留上表中的品牌琥珀色值。强调按钮使用品牌墨色 `#1F2933` 的文字与图标，保持可读性。添加照片采用与其他按钮一致的系统常规尺寸，不显示展开箭头，点击后仍打开原生菜单。

## 文案原则

“不重新编码”明确指音视频流复用，以及支持直通保留的静态图编码路径。改变图片格式、主动调整图片质量或转换 HDR 增益图可能涉及图像编码，不承诺所有路径逐字节不变。

“保留封面”指读取源时间标记并映射实际视频帧，记录对齐误差；不承诺经过时间线映射后，所有容器中的时间数字仍完全相同。

“保留 HDR”区分已有增益图原样保留、可解释模型转换和私有数据保留；文件数据保留不等于所有设备能够显示同样的 HDR 效果。
