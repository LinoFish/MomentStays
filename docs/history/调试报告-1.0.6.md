# 1.0.6 小米动态照片转换修复

新增的 3 张小米动态照片在 1.0.5 均能识别，但转换失败，错误为 `Movie presentation timeline shifted`。修复后全部成功，无需修改转换选项。

根因是旧校验比较了 AVAssetReader 返回的缓冲区，而缓冲区可以包含多个 AAC 音频包。测试样例的源视频与输出 MOV 包含相同的压缩包，逐包时间一致；缓冲区分组不同，触发了时间位移误报。

新版逐个实际样本读取时间和大小，核对样本数量、大小序列、压缩数据哈希及 PTS。没有放宽时间校验、删除音频或重新编码，原始封面时间及文件名保持。

验证结果：

- 3 张小米照片全部成功，每张 89 个 AAC 包；原始 MP4 与输出 MOV 的音频 stsz、stts 表独立比对一致，音视频样本 PTS 位移均为 0。
- 项目内共 137 张原片：134 转换成功，0 失败，3 跳过。跳过的 3 张为原有不含动态视频的静态照片。
- 137 张原片 SHA-256 全部保持，源文件未修改。
- 134 组输出的主 JPEG 压缩数据、辅助图、原文件名和文件哈希均独立复核通过；音视频样本 PTS 位移均为 0，封面采样对齐最大偏差约 10.778 微秒。
- 全量结果位于 `converted-1.0.6`；另有 3 张小米专项结果位于 `converted-1.0.6-xiaomi`。
- 32 项原生转换检查、辅助轨专项、批量输入、文件名保留以及 30 项 Python 单元测试通过。

新版继续支持 macOS 12，提供 Intel / Apple Silicon 通用应用。没有访问或写入 Apple「照片」图库，iPhone 导入及 HDR 显示、Apple Silicon 实机运行仍未验证。
