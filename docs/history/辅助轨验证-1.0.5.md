# 辅助轨验证：Motion-Live 1.0.5

测试集的辅助轨为 **2048 × 1536、仅一帧**。可以提取高清画面，但不能替代主轨提供连续动态视频。新版允许选择辅助轨制作 Live Photo；只有实际包含连续帧、且原始封面时间能映射到该轨的文件才会成功。不会循环、插值或延长单帧来制造动态效果。

## 如何使用

- 主界面「视频轨」选择主运动轨或辅助影像轨。
- 「导出」选择仅 Live Photo、Live Photo ＋ 单独导出辅助轨、仅单独导出辅助轨。
- 独立文件使用原名主体加 `.auxiliary.mov`，不含音频或 Live Photo 配对标识。
- 高级设置中的「独立导出时允许修复辅助轨的零时长」默认关闭。

同时导出时，导入 Apple「照片」只选择同名 JPEG 和配对 MOV；辅助 MOV 单独保存。不同导出设置请使用新的输出位置，避免与已有清单冲突。

## 全量结果

在 Intel macOS 12 上验证：

- 默认设置：89 条辅助轨导出成功；8 条因原始样本时长为 0，被系统忽略而报告失败。
- 开启零时长修复：测试集全部成功。结果位于本地输出文件夹。
- 修复均采用主轨最短有效帧长，仅改变导出副本的时长字段，不修改原片、压缩样本或样本起始时间。
- 97 个输出逐样本压缩数据、PTS 和输出文件哈希均通过检查；8 个修复样本另与原始 MP4 中的压缩样本直接计算哈希核对一致。
- 原始照片的 SHA-256 全部保持。

## 回归与限制

专项测试覆盖独立导出、配对加辅助轨、续转、缺轨报错、单帧拒绝、零时长显式修复，以及连续第二视频轨的选择和封面时间。连续第二轨使用原有视频构造的双轨测试容器，不代表本批照片具有连续辅助画面。

32 项原生转换检查、30 项 Python 单元测试、批量输入及文件名保留检查通过。视频和静态 JPEG 均不重新编码。没有访问 Apple「照片」图库；iPhone 导入、最终封面及 HDR 显示，以及 Apple Silicon 实机运行尚未验证。
