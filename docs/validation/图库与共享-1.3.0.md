# 图库与共享发行验证 1.3.0

平台：Intel / macOS 12；部署目标 macOS 12.0。以下为 1.3.0 的验证范围，不包含真实图库或接收端验收。

## 新增实现

- 系统图库按相册、转换方向筛选候选，读取完整原件；原片与编辑版明确选择，不混配。
- iCloud 下载需勾选；普通静态图跳过，资源缺失保留具体原因。
- 安卓转苹果可直接入相册，图片与 MOV 使用同一资产创建请求，保留资源文件名、拍摄日期与位置。
- 持久去重日志保护异常提交；已有资产只重试相册关联，目标缺失不自动重建，日志损坏停止写入。
- 用户可启用当前范围的运行期间增量监测，切换范围后旧回调不会进入新范围，退出停止。
- 苹果转安卓支持文件夹、直接共享、文件夹并共享。共享使用完整文件 URL，暂存文件校验 SHA256，同名安全消歧。
- 最近结果支持重试交付、查看文件与清理自身任务缓存。退出保留缓存，共享期间禁止删除，用户输出和图库资产不随缓存清理删除。

## 安装包

版本 1.3.0，内部构建 16。默认仅编译 x86_64，不将 Intel 二进制标为通用版。`scripts/make_dmg.sh` 从应用读取版本和实际架构，生成对应 DMG、ZIP 与 SHA256 清单，临时打包目录自动清理。

本次源码发布已重新编译 Intel 1.3.0 正式应用，并完成图标打包、严格本地签名及实际架构核对。沙箱中的媒体编码和图标工具受系统服务限制，相应步骤已在正常 macOS 环境中完成。没有运行真实图库、共享接收或窗口弹窗验收。

本次只发布源码，不重新生成或上传 DMG / ZIP。需要安装包时从本次源码重新构建，再运行打包脚本。既有本地安装包和验证报告继续由忽略规则排除，不作为本次源码发布的构建证明。

应用采用本地 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证。网络分发后首次启动可能需要用户在系统中允许打开。
