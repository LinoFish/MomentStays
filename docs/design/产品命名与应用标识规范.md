# 产品命名与应用标识规范

状态：macOS 本次已实施命名、本地化与非破坏标识迁移，已通过 macOS 专项及正式产物验证，随 1.7.0 发布；已发布旧版本保持不变。iOS 标识与 App Group 迁移留待独立平台验证。

## 产品名称与域名

- 默认产品名及英文名为 **MomentStays**。
- **留刻**是暂定中文翻译，不替代默认英文名称。
- 产品域名为 `momentstays.linofish.com`。
- Release 标题默认使用英文及产品名 MomentStays；正文英文在前，附内容一致的中文翻译。发布说明的内容与长度遵循根目录 [AGENTS.md](../../AGENTS.md)。

## 应用标识

- 主应用目标标识统一为 **`com.linofish.momentstays`**，采用产品域名的倒域名形式。
- 不采用 `stays` 或 `com.linofish.stays`。
- 应用标识不随界面语言、中文译名、版本号或安装包显示名变化。
- 扩展在主标识后追加职责后缀，例如分享扩展使用 `com.linofish.momentstays.share`。不同平台的注册与签名配置按各平台要求处理。

## 现有应用迁移

macOS 本次使用 `com.linofish.momentstays`，迁移前标识为 `app.motionlive.converter`。iOS 工程本轮仍为 `com.app9x3k2q.momentstays`，分享扩展后缀 `.share`，两者共同使用 `group.com.app9x3k2q.momentstays`；本轮不单独替换其中任何一项，以免破坏跨进程容器与签名配置。

macOS 非沙箱包无 App Group，保留既有 `~/Library/Application Support/Motion-Live` 任务与缓存路径；首次启动从旧偏好域仅复制新域缺少的键，记录来源、时间和键名，保留旧域。此迁移可重入且不覆盖新设置，不移动或删除用户输出或旧 App。新标识可能需要重新授予 Photos 权限。

物理包为 `MomentStays.app`；中文本地化显示「留刻」，英文及其他语言回退 MomentStays。DMG/ZIP 为 `MomentStays-<版本>-universal.dmg/.zip`，英文卷名为 `MomentStays <版本>`。旧 `留刻.app` 不会因改名自动被 Finder 覆盖；先退出旧版，安装新版并核对既有任务后，由用户自行移除旧版，安装器不静默删除。

iOS 主 App、分享扩展、测试目标、App Group 及两处共享容器访问必须统一迁移，并需开发者注册/签名和真机验证；本次 macOS 发布不宣称 iOS 已迁移或验收。迁移说明见 [UPGRADING.txt](../../apple/macos/packaging/UPGRADING.txt)。

名称本地化与下一次发布安排见[中英文命名与下次发布计划](../product/中英文命名与下次发布计划.md)。
