# MomentStays UI 交互与进度优化待办

记录日期：2026-11-03。

用户已确认将微过渡、进度区和顶部操作栏一并实施。以下功能已完成，验收记录见文末。HDR 悬停展开与舒适卡片布局作为本次调整的基础保留。

## 已确认：微过渡动画

| 待办 | 效果 | 建议时长 | 优先级 |
|---|---|---|---|
| [x] 照片选择反馈 | 对号淡入、边框颜色柔和变化，卡片尺寸和位置稳定 | 100–140 ms | 优先 |
| [x] 分类选中反馈 | 选中底色柔和过渡，照片内容及时更新 | 140–180 ms | 优先 |
| [x] 文件详情展开 | 箭头旋转、详情区域平滑展开及文字淡入 | 180–220 ms | 优先 |
| [x] 预览面板开合 | 面板轻微淡入淡出，保留原生可拖拽分栏 | 180–220 ms | 后续 |
| [x] 确认更换封面 | 新封面短暂交叉淡化，当前标记颜色过渡 | 100–140 ms | 后续 |
| [x] 任务状态切换 | 处理、完成、停止等状态的文字、图标及颜色柔和变化 | 140–180 ms | 后续 |

共同要求：

- 动画用于解释状态变化，操作立即响应，快速连续操作时可中断、反向过渡。
- 尊重系统减少动态效果设置，以静态更新或简单淡化替代位移动画。
- 时间线拖动和逐帧预览紧跟指针；封面淡化仅用于明确确认更换封面。
- 照片批量加载、网格重排和卡片悬停不采用大面积入场、放大或弹跳动画。
- 不为高频进度数字、文件名和每一帧反复触发整体布局动画。

## 已确认：进度区调整

- [x] 将进度信息移至照片分类栏下方，显示约 56–64 pt 高的任务进度区。
- [x] 优先使用横向进度条，呈现“正在转换 · 已处理 34 / 120 张”等真实数量信息。
- [x] 当前文件名作为次要文字，长文件名中间截断；停止入口清晰可见。
- [x] 停止入口统一位于顶部右侧的主操作位置；进度区不重复提供停止按钮。
- [x] 底部移除重复进度文字、进度条和当前文件名；错误、停止结果和交付反馈仍须有清晰可恢复的展示位置。
- [x] 进度区出现和收起采用轻微过渡；任务结束后收起，异常信息按需要保留。
- [x] 转换期间照片列表保持清晰；不以全列表模糊蒙版持续遮挡内容。
- [x] 已知数量使用确定型进度，扫描或准备阶段不能量化时使用不确定型横向进度，不伪造百分比。
- [x] 数量比例不等同于剩余时间；未获得可靠估算前不显示预计完成时间。

## 已确认并实施：底部按钮移至顶部

顶部操作栏已采用主次分组，底部不再设置常驻全局操作栏。

- 全局转换操作集中在顶部工具栏右侧，“开始转换”作为唯一高亮主按钮。
- “开始转换”在原位切换为“停止 / 停止中”；设置区按任务状态锁定时，停止按钮独立保持可用。
- 导出设置为次要按钮；最近结果、打开输出位置、报告及共享结果按任务状态放入全局“更多 / 结果”菜单。
- 照片预览、分类、列表布局和列表清空等操作仍属于照片区域；文件详情仍贴近当前照片。
- 窄窗口优先保留主操作和关键转换配置，收纳次要操作，避免挤压方向选择和输出位置。
- 全局操作与进度均已迁出底部，撤除常驻底部操作栏；异常恢复、停止结果和图库监测控制安置在照片区域内的反馈区。

## 后续验收

- 宽窄窗口、深色模式、减少动态效果、连续切换及批量任务场景。
- 选中状态与滚动位置不因动画丢失；时间线预览没有额外延迟。
- 转换、停止、停止中、完成、失败和交付中各阶段均有明确反馈。
- 主操作、停止、异常恢复和文件详情始终可通过键盘操作。
