# 单一工作台与可选预览

当前正式界面采用单一工作台，不提供简易模式或模式切换。

- 保留原生红黄绿窗口按钮与透明标题栏。
- 顶部并列展示「安卓 → 苹果实况」「苹果实况 → 安卓」两个可用方向；安卓直接互转尚未实现。
- 「添加照片」使用系统原生橙色的按钮，无展开箭头，尺寸与相邻按钮一致；点击显示系统菜单，提供文件／文件夹与系统图库两个入口；保存位置及适用的安卓目标紧邻其后，窄窗口自动换行。
- 分类常驻显示待转换、已完成、静态照片、需检查与全部的数量，默认显示待转换。
- 预览窗格默认关闭，通过「预览」按钮或 ⌥⌘P 开关，不改变选中项或转换设置。
- 「更多选项…」打开设置面板；底部显示转换进度与操作。

当前实现见 [工作台](../../../gui/WorkspaceView.swift)和[照片队列](../../../gui/PhotoQueueView.swift)。旧版多模式提案和独立演示已删除。
