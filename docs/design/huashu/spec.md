# MomentStays UI 方向探索

假设：本次针对当前仓库的 macOS SwiftUI 应用，不延伸为 iOS 产品或营销网站。主要受众是需要迁移动态照片、批量转换并送回系统图库的普通用户。

共同内容：照片选择、双向转换、队列、图片格式、交付位置、源封面时间、原始音视频复用、HDR 条件提示、转换进度。各版按场景调整信息顺序与默认暴露程度。

共同尺寸：桌面参考视口 1440×900，应用窗口约 1200×680；同时检查 375×812 的原型查看体验。主角素材为原创山湖 SVG 插画，所有文件名、数量、时间、进度均为虚构。

初稿边界：HTML 可交互视觉原型；未连接 SwiftUI、转换引擎、PhotoKit 或真实媒体。导入按钮载入示意状态，转换按钮播放模拟进度。暗房滑杆只演示时间线，不更改真实封面。

形式五问：服务于转换前的判断；观看距离为桌面操作；三版温度分别为克制、沉浸、轻松；信息容量分别为批量、单张预览、首次任务；共同视觉母题为「静态原件与动态时间共存」。
