# 事实与假设

产品事实以本工作区 README.zh-CN.md、gui/WorkspaceView.swift 和品牌文档为准：macOS 12+ 原生 SwiftUI；支持双向照片转换；文件、图库与共享交付；源封面映射；压缩音视频复用；HDR 有格式与模型限制。本任务不引用远程发行版本，不把现有文档中的版本号写进 UI。

Skill 来源：https://github.com/alchaincyf/huashu-design ，本次安装 master 分支；元数据版本 3.0.0。已打开远程仓库核验来源。

界面数据全部虚构，6 张、3 秒、1.20 秒均非产品性能或真实媒体指标。两步式界面与大图预览是设计建议，未声称已在原生应用实现。
