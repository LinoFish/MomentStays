# 照片下方的封面时间线与悬浮预览

用户需求：「预览界面可以在照片下方有一个进度条，显示封面所在位置，并且可以在鼠标悬浮在进度条时，显示所处位置的画面」。

在原生工作台缩略图下加入时间条：琥珀标记固定表示源封面帧，系统强调色圆点表示鼠标位置；鼠标移动时用实际视频帧临时替换卡片画面，并标明实际帧时间。鼠标移出后恢复静态照片。仅预览，不改变封面或转换参数。

封面定位复用转换引擎的 sourceCoverTiming，读取时间戳或原始帧号，保留歧义拒绝逻辑。视频预览将媒体时间映射至编辑后的播放时间，并裁掉首尾空白编辑；普通视频、变帧率、非零首帧时间均用真实样本定位。缺失或无法唯一定位的封面不显示虚构标记，仍可在可读取的视频上悬浮预览。

Android 动态照片只向应用拥有的临时目录提取内嵌视频；Apple 实况照片验证 ContentIdentifier 后读取配对视频。后台解码，最多一个在途帧请求并合并鼠标移动；视图离开时取消准备与更新，预览会话释放后删除自身临时文件。预览读取主动态轨，不播放音频。

macOS 12 使用 NSTrackingArea 获取鼠标位置；VoiceOver 可调整时间线位置。真实照片加载前的占位继续使用正式 Logo，色调跟随系统。

验证入口：scripts/check_motion_preview.sh（真实构造媒体与缓存检查）、scripts/check_motion_hover.py（原生鼠标事件、悬浮取帧与移出恢复）、scripts/check_swiftui_ui.py（窗口布局）、scripts/check_gui_engine.py（共用封面映射后的转换回归）。

已通过 43 项媒体预览检查（包含普通、变帧率、分数帧率、非零起始 PTS、正反向封面、实际首尾帧解码、缺失/越界封面、取消与缓存释放）、3 项原生悬浮检查（0.80 秒实际取帧、移出恢复、深色模式）及 32 项转换引擎回归。原生截图位于 .build/gui/ui-checks/hover.png、hover-exit.png 和 hover-dark.png，均为构造媒体，不使用个人照片。

新增时间条后的 15 项原生窗口布局回归也全部通过；窄窗、设置面板、任务进度、深色外观与来回缩放下，主要操作和队列均保持可见。
