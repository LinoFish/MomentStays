# 本地样片与隐私

基础单元测试、原生引擎和工作区回归使用构造媒体，不需要个人照片。真实样片回归是独立的可选检查；样片来源、原始路径、拍摄日期、机型、文件指纹和完整报告只保存在本地。

## 通用占位路径

这些名字只表示测试角色，不是仓库附带的照片：

| 路径 | 用途 |
| --- | --- |
| `pictures/sample-motion.MP.jpg` | 主运动轨、已有输出和厂商容器回归 |
| `pictures/sample-sparse.MP.jpg` | 单帧辅助轨 |
| `pictures/sample-zero-duration.MP.jpg` | 显式零时长辅助轨修复 |
| `pictures/sample-device-motion.HEIC` | HEIC 容器、编码与属性保持 |
| `pictures/honor/sample-private-hdr.jpg` | 私有静态扩展保持 |
| `pictures/honor/sample-ultra-hdr.jpg` | 通用增益图保持 |
| `pictures/vendor-samples/` | AAC 缓冲区重新分组样片 |

需要在本地提供符合相应回归假设的素材。测试中的样本布局、轨道数量与编码断言仍有条件限制；随意选择另一张照片不能视为同一回归案例。

## 可配置来源

Apple HDR 和 HEIC 反向检查支持以下环境变量，设置真实路径时不要把命令记录或配置提交到仓库：

- `MOTIONLIVE_APPLE_SAMPLES`：原片及完整编辑版测试配对所在目录，默认 `pictures/apple/`。
- `MOTIONLIVE_APPLE_REFERENCE`：公开参考 HEIC 的本地副本，默认 `pictures/fixtures/apple-reference.HEIC`。
- `MOTIONLIVE_HEIC_PAIR`：已生成的 Apple 格式配对目录，包含 `manifest.json`，默认 `pictures/fixtures/apple-pair/`。视频文件名从清单读取。

校验报告可能记录源路径、日期、EXIF 与哈希，保存在 `.build/` 或其他忽略目录。测试不会自动上传样片，也不应把真实报告复制到公开文档。

## 发布前检查

运行 `python3 scripts/check_publish.py`，检查拟发布的源码与文档。它会拒绝媒体文件、私钥、常见访问令牌、个人绝对路径和可识别的样片名称/指纹。

`.gitignore` 额外忽略所有常见照片、视频和安装包扩展名，以及 `.nimbalyst/`、`.local-archive/`、`local-data/`、`artifacts/`。旧资料保存在本地归档中，可恢复，但不进入 GitHub 当前目录。
