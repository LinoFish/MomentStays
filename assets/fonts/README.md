# Website font attribution / 网站字体致谢

The GitHub Pages website distributes regular (400) and bold (700) WOFF2 subsets of **Noto Serif SC**, a [Noto CJK](https://github.com/notofonts/noto-cjk) font developed with [Adobe](https://github.com/adobe-fonts/source-han-serif). Its CSS family alias is `MS Serif`.

网站在 `assets/fonts/ms-serif-regular.woff2` 和 `assets/fonts/ms-serif-bold.woff2` 中自托管 Noto Serif SC 子集；原生 App 使用系统字体。
